用户可通过 `tencent_docs_openapi_setup` 打开本机设置页面，首次保存自己的应用配置并授权；以后由 `tencent_docs_openapi_login` 直接打开官方授权页。本机设置页、HTTPS 静态回调页、本机回调、授权码换 Token 和密钥库写入已完成模拟集成测试；由于尚无审核通过的测试应用，腾讯官方页的真实授权仍未验证。

## 边界

- 官方 MCP 后续可能增加工具；本项目不再动态代理官方清单，发版前需重新对照去重。
- `tencent_docs_openapi_*` 使用正式公开接口，但当前没有可用的开放平台 OAuth 凭据，因此真实账号调用尚未验证。
- 题目编辑、网页文件列表和永久删除等旧扩展不是腾讯公开 API；网页升级后可能需要更新。
- 不绕过账号登录、文件权限、访问策略或平台配额。
- 本项目不声称已枚举腾讯文档网页中所有隐藏、实验或企业专属接口。
