# 腾讯文档 MCP 能力矩阵

更新日期：2026-09-11

## 官方 MCP

官方端点：`https://docs.qq.com/openapi/mcp`

官方介绍：[CloudBase MCP Plaza 的腾讯文档页面](https://developer.cloud.tencent.com.cn/mcp/server/11803)

本项目实际调用 `tools/list` 获得 224 个工具，并保留官方返回的名称、说明和 JSON Schema。工具数会随腾讯更新而改变，不在代码中写死。

| 分类 | 2026-09-11 实时数量 | 主要能力 |
| --- | ---: | --- |
| 文档 `doc.*` | 46 | 创建、读取结构、插入/替换内容、表格、图片、附件、批注、格式 |
| 表格 `sheet.*` | 25 | 单元格、区域、样式、行列、合并、冻结、筛选、图片 |
| 幻灯片 `slide_*` | 75 | 页、形状、文字、图片、表格、图表、动画、主题、备注、评论 |
| 智能表 `smartsheet.*` | 29 | 表、视图、字段、记录、仪表盘、自动化 |
| 文件管理 `manage.*` | 18 | 创建、搜索、复制、移动、改名、删除到回收站、权限、导入导出 |
| 流程图 `flowchart.*` | 5 | 读取、新增、修改、移动、删除元素 |
| 智能文档 `smartcanvas.*` | 4 | 读取、编辑、查找、顶层页面 |
| AI Canvas | 3 | 页面来源、重新导入、绑定智能表 |
| OCR | 3 | 文字提取、转 Word、转 Excel |
| 创建和其他 | 16 | Markdown/Mermaid 创建、空间节点、用户信息、网页抓取等 |

已用真实账号验证：

- 从已登录 Chrome 的登录态获取官方 MCP Token，Token 未写入文件或日志。
- 动态读取 224 个工具，名称无重复。
- 一个无副作用的官方工具经 `gateway.py` 转发成功。

## 边界

- 官方 224 个工具是实时发现的官方能力，不由本项目承诺稳定性和配额。
- 扩展工具不是腾讯公开 API；网页升级后可能需要更新。
- 不绕过账号登录、文件权限、访问策略或平台配额。
- 本项目不声称已枚举腾讯文档网页中所有隐藏、实验或企业专属接口。
